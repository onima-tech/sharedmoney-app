# SharedMoney web

Public site for SharedMoney. The Expo app lives in `mobile/`.

This package is the marketing homepage, the SEO pages (expense-tracker and calculator routes), and the `/split` guest bill pages. Static legal and support HTML in `public/` is what production serves for `/privacy`, `/terms`, `/delete-account`, and `/support`.

React, TypeScript, and Vite. `npm run dev` starts the site, `npm test` runs Vitest, and `npm run build` typechecks, builds, and generates the SEO pages.
